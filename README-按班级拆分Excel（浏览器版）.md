## 按班级拆分 Excel（浏览器版）

打开 [index.html](file:///Users/newsunlee/Desktop/AI%20for%20learning/exam%20analyze/index.html)，上传 Excel 后会在浏览器本地完成：
- 拆分模式：读取指定工作表，按一个或多个指定列进行拆分
- 合并模式：选择多个 Excel 按行合并为一个 .xlsx
- 自动打包成一个 .zip 并下载
- 默认开启“导出 Excel 工整化”（自动列宽、表头浅色底纹、边框、居中对齐）

## GitHub Pages 打开方式

仓库根目录包含 `index.html`，开启 GitHub Pages 后可直接用站点根路径打开：
- `https://<用户名>.github.io/<仓库名>/`

如果你没有开启 Pages，也可以用带文件名的链接访问具体页面。

## 使用方式

### 方式 A：直接双击打开（需要能联网加载依赖库）
1. 双击打开 html
2. 选择“拆分模式”或“合并模式”
3. 拆分模式下：上传文件，选择工作表与拆分列（支持多选）
4. 合并模式下：一次选择多个文件，点击“开始合并并下载”
5. 处理完成后自动下载结果文件

### 方式 B：本地启动（推荐，更稳定）
在该目录执行：

```bash
python3 -m http.server 8000
```

浏览器打开：
- http://localhost:8000/

## 说明
- 默认不会把你的 Excel 上传到服务器；处理在浏览器本地完成。
- 如果拆分列存在合并单元格/空洞，勾选“对拆分列向下填充”即可。
- 班级名如含 `/\\:*?"<>|` 等非法字符，会自动替换，避免下载时报错。
- 如果数据量很大且导出变慢，可取消勾选“导出 Excel 工整化”来提速。
- 导出“工整化”样式由 ExcelJS 生成；如离线使用需确保 exceljs 也能加载（或改为本地引用）。
