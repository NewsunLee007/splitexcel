## 按班级拆分 Excel（浏览器版）

打开 [按班级拆分Excel（浏览器版）.html](file:///Users/newsunlee/Desktop/AI%20for%20learning/exam%20analyze/按班级拆分Excel（浏览器版）.html)，上传 Excel 后会在浏览器本地完成：
- 读取第一个工作表（可在页面里切换工作表）
- 选择“班级”列（支持自动识别/手动选择）
- 按班级拆成多个 .xlsx
- 自动打包成一个 .zip 并下载
- 默认开启“导出 Excel 工整化”（自动列宽、表头浅色底纹、边框、居中对齐）

## 使用方式

### 方式 A：直接双击打开（需要能联网加载依赖库）
1. 双击打开 html
2. 拖拽/选择 Excel 文件
3. 选择工作表与班级列（默认自动识别）
4. 点击“开始拆分并打包”，浏览器会下载 zip

### 方式 B：本地启动（推荐，更稳定）
在该目录执行：

```bash
python3 -m http.server 8000
```

浏览器打开：
- http://localhost:8000/%E6%8C%89%E7%8F%AD%E7%BA%A7%E6%8B%86%E5%88%86Excel%EF%BC%88%E6%B5%8F%E8%A7%88%E5%99%A8%E7%89%88%EF%BC%89.html

## 说明
- 默认不会把你的 Excel 上传到服务器；处理在浏览器本地完成。
- 如果班级列存在合并单元格/空洞，勾选“对班级列向下填充”即可。
- 班级名如含 `/\\:*?"<>|` 等非法字符，会自动替换，避免下载时报错。
- 如果数据量很大且导出变慢，可取消勾选“导出 Excel 工整化”来提速。
- 导出“工整化”样式由 ExcelJS 生成；如离线使用需确保 exceljs 也能加载（或改为本地引用）。
